# Machine-Learning-
"A collection of Machine Learning algorithms implemented from scratch using core mathematical concepts such as Statistics, Linear Algebra, Probability, and Calculus, without using machine learning frameworks like Scikit-Learn."

#Linear-Regression:
Linear Regression is a Machine Learning algorithm used to predict a number based on past data.
Think of it as drawing the best-fit straight line through data points.

#Logistic-Regression:
It is an machine learning algorithm used for classification
It predicts categories such as:

Yes / No
True / False
Pass / Fail
Spam / Not Spam
Disease / No Disease
